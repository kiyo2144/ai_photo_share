# AI実装コンテキスト

## プロジェクト概要

友人同士で旅行や日常の写真を共有する、小規模なInstagram風Webアプリを作る。投稿一覧は誰でも閲覧でき、登録・ログインしたユーザーだけが投稿、編集、削除を行える。

実装は初学者が処理を追える単純さを優先する。指示されていない機能、依存パッケージ、抽象化を勝手に追加しない。

## 技術と構成

- Python 3.13
- Flask 3.1.3
- Peewee 4.5.3
- SQLite
- 単一の`app.py`を使用する
- HTMLはJinjaテンプレートで生成する
- Flask-Loginで認証状態と保護ルートを扱う
- Flask-SessionとCacheLibでセッションをサーバー側へ保存する
- Flask-WTFでフォーム、入力検証、CSRF対策を行う
- Pillowで画像の内容とメタデータを検証する
- python-dotenvで開発環境の環境変数を読み込む

### ディレクトリの役割

- `app.py`: アプリ設定、モデル、フォーム、ルート、補助関数
- `templates/`: Jinjaテンプレート
- `static/`: CSSとJavaScript。ユーザー投稿画像は置かない
- `uploads/`: プロジェクト直下に置くユーザー投稿画像の保存先
- `instance/`: SQLite DBやセッションなどのローカル実行時データ
- `tests/`: 必須機能完成後に追加するpytestテスト
- `docs/`: 要件と設計資料

`uploads/`のファイルは、専用のFlaskルートから安全に返す。利用者が送信した元ファイル名は保存名に使わず、UUIDなどでランダムな名前を生成する。

## 初版の機能

- 表示名、メールアドレス、パスワードによるユーザー登録
- ログインとログアウト
- 写真1枚と必須キャプションの投稿
- 投稿の新着順一覧
- 投稿者本人によるキャプション編集
- 投稿者本人による投稿削除
- 日本語の入力・権限エラー表示

投稿詳細、いいね、コメント、検索、フォロー、通知、画像加工は初版に含めない。

## 主要な仕様

### ユーザー

- 表示名は必須、50文字以内、重複可
- メールアドレスは必須、254文字以内、重複不可
- メールアドレスは前後の空白を除き、小文字へ統一する
- パスワードはハッシュだけを保存する
- メールアドレスは公開画面に表示しない

### 投稿と画像

- キャプションは必須、空白だけは不可、1〜200文字
- 対応形式はJPEG、PNG、WebP
- 最大ファイルサイズは10MB
- DBには相対保存先、MIMEタイプ、容量、幅、高さを保存する
- 画像本体と元ファイル名はDBに保存しない
- 日時は日本時間で統一する

### 画面とルート

- `GET /`: 投稿一覧、`posts/index.html`、ログイン不要
- `GET, POST /register`: 登録、`auth/register.html`
- `GET, POST /login`: ログイン、`auth/login.html`
- `POST /logout`: ログアウト、ログイン必須
- `GET, POST /posts/new`: 投稿作成、`posts/new.html`、ログイン必須
- `POST /posts/<int:post_id>/edit`: キャプション編集、本人のみ
- `POST /posts/<int:post_id>/delete`: 投稿削除、本人のみ

## セキュリティ上の必須条件

- すべてのPOSTでCSRFトークンを検証する
- 投稿、編集、削除、ログアウトはサーバー側でログインを確認する
- 編集と削除は投稿者本人だけに許可する
- `next`はアプリ内の安全な相対パスだけを許可する
- 画像は拡張子や送信されたMIMEタイプだけで判断せず、Pillowで検証する
- `SECRET_KEY`などの秘密情報は環境変数から取得する
- 例外、パスワード、秘密情報を画面やログへ出さない
