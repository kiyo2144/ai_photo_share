# 写真共有アプリ ルーティング設計書

## 1. ルーティング設計の方針

- 画面表示にはGET、データ変更にはPOSTを使用する。
- POST処理の成功後は別のURLへリダイレクトし、再読み込みによる二重送信を防ぐ。
- すべてのPOSTリクエストでCSRFトークンを検証する。
- 投稿の作成、編集、削除とログアウトにはログインを必要とする。
- 編集と削除では、ログインユーザーが投稿者本人であることをサーバー側で確認する。
- 投稿詳細といいねのルートは初版に含めない。

## 2. ルート一覧

| エンドポイント名 | HTTPメソッド | URL | ログイン | テンプレート | 役割 |
| --- | --- | --- | --- | --- | --- |
| `post_list` | `GET` | `/` | 不要 | `posts/index.html` | 投稿一覧を新しい順に表示する |
| `register` | `GET` | `/register` | 不要 | `auth/register.html` | ユーザー登録フォームを表示する |
| `register` | `POST` | `/register` | 不要 | `auth/register.html` | 入力を検証してユーザーを登録する |
| `login` | `GET` | `/login` | 不要 | `auth/login.html` | ログインフォームを表示する |
| `login` | `POST` | `/login` | 不要 | `auth/login.html` | 入力を検証してユーザーを認証する |
| `logout` | `POST` | `/logout` | 必須 | なし | ログアウトして投稿一覧へ移動する |
| `post_create` | `GET` | `/posts/new` | 必須 | `posts/new.html` | 投稿作成フォームを表示する |
| `post_create` | `POST` | `/posts/new` | 必須 | `posts/new.html` | 入力を検証して投稿を作成する |
| `post_edit` | `POST` | `/posts/<int:post_id>/edit` | 必須・本人のみ | なし | 一覧内フォームからキャプションを更新する |

## 3. 各ルートの詳細

### 3.1 投稿一覧

- **エンドポイント名**: `post_list`
- **HTTPメソッド**: `GET`
- **URL**: `/`
- **ログイン**: 不要
- **テンプレート**: `posts/index.html`

投稿を投稿日時の新しい順で取得して表示する。ログインユーザーが投稿者本人の場合だけ、その投稿に編集フォームと削除フォームを表示する。

投稿が0件の場合も正常な画面として扱い、案内メッセージを表示する。

### 3.2 ユーザー登録

- **エンドポイント名**: `register`
- **HTTPメソッド**: `GET`, `POST`
- **URL**: `/register`
- **ログイン**: 不要
- **テンプレート**: `auth/register.html`

#### GET

- 登録フォームを表示する。
- ログイン中の場合は投稿一覧へリダイレクトする。

#### POST

- メールアドレス、パスワード、確認用パスワードを検証する。
- 成功時はパスワードをハッシュ化してユーザーを保存し、ログイン画面へリダイレクトする。
- 失敗時はエラーメッセージとともに登録画面を再表示する。

### 3.3 ログイン

- **エンドポイント名**: `login`
- **HTTPメソッド**: `GET`, `POST`
- **URL**: `/login`
- **ログイン**: 不要
- **テンプレート**: `auth/login.html`

#### GET

- ログインフォームを表示する。
- 任意の`next`クエリパラメーターを受け取る。
- ログイン中の場合は投稿一覧へリダイレクトする。

#### POST

- メールアドレスとパスワードを検証する。
- 認証成功時はユーザーIDをセッションへ保存する。
- 有効な`next`があればそのパスへ、なければ投稿一覧へリダイレクトする。
- 認証失敗時は、メールアドレスまたはパスワードが正しくないことを表示して同じ画面を再表示する。

`next`にはアプリ内の相対パスだけを許可する。スキームやホストを含むURL、`//`から始まるURL、不正な値は拒否し、投稿一覧を遷移先とする。

### 3.4 ログアウト

- **エンドポイント名**: `logout`
- **HTTPメソッド**: `POST`
- **URL**: `/logout`
- **ログイン**: 必須
- **テンプレート**: なし

セッションからログイン情報を削除し、完了メッセージを設定して投稿一覧へリダイレクトする。GETリクエストではログアウトしない。

### 3.5 投稿作成

- **エンドポイント名**: `post_create`
- **HTTPメソッド**: `GET`, `POST`
- **URL**: `/posts/new`
- **ログイン**: 必須
- **テンプレート**: `posts/new.html`

#### GET

- 投稿作成フォームを表示する。
- 未ログインの場合は、`next=/posts/new`を付けてログイン画面へリダイレクトする。

#### POST

- 写真の有無、実際の画像形式、10MBの容量制限、200文字以内のキャプションを検証する。
- 成功時は画像と投稿データを保存し、投稿一覧へリダイレクトする。
- 失敗時は、途中まで保存したデータや画像を残さず、エラーメッセージとともに投稿作成画面を再表示する。

### 3.6 キャプション編集

- **エンドポイント名**: `post_edit`
- **HTTPメソッド**: `POST`
- **URL**: `/posts/<int:post_id>/edit`
- **ログイン**: 必須、投稿者本人のみ
- **テンプレート**: なし

一覧画面内のフォームから、200文字以内のキャプションを受け取る。

- 成功時は更新メッセージを設定して投稿一覧へリダイレクトする。
- 入力エラー時はエラーメッセージを設定して投稿一覧へリダイレクトする。
- 投稿が存在しない場合は404を返す。
- 投稿者本人でない場合は403を返す。

### 3.7 投稿削除

- **エンドポイント名**: `post_delete`
- **HTTPメソッド**: `POST`
- **URL**: `/posts/<int:post_id>/delete`
- **ログイン**: 必須、投稿者本人のみ
- **テンプレート**: なし

一覧画面の削除確認で了承された後に実行する。

- 投稿データと対応する画像ファイルを削除する。
- 成功時は削除メッセージを設定して投稿一覧へリダイレクトする。
- 削除処理に失敗した場合はログへ記録し、利用者向けメッセージを設定する。
- 投稿が存在しない場合は404を返す。
- 投稿者本人でない場合は403を返す。

## 4. 認証とエラーの共通動作

### 4.1 未ログイン時

- 保護されたGETルートへのアクセスは、目的の相対パスを`next`に設定してログイン画面へリダイレクトする。
- 保護されたPOSTルートへの未ログインアクセスも拒否し、ログイン画面へ誘導する。未送信のフォーム内容や削除操作はログイン後に自動実行しない。

### 4.2 権限と存在確認

- 投稿を検索し、存在しない場合は404を返す。
- 編集と削除では投稿者IDを確認し、一致しない場合は403を返す。
- 画面上でボタンが非表示でも、サーバー側の確認を省略しない。

### 4.3 POST処理

- すべてのPOSTでCSRFトークンを検証する。
- 正常なPOST処理の後はリダイレクトする。
- `GET /logout`、`GET /posts/<post_id>/edit`、`GET /posts/<post_id>/delete`は用意しない。

## 5. 画面遷移とリダイレクト先

| 操作 | 成功時 | 失敗時 |
| --- | --- | --- |
| ユーザー登録 | ログイン画面 | 登録画面を再表示 |
| 通常のログイン | 投稿一覧 | ログイン画面を再表示 |
| `next`付きログイン | 検証済みの目的画面 | ログイン画面を再表示 |
| ログアウト | 投稿一覧 | 投稿一覧でエラーを表示 |
| 投稿作成 | 投稿一覧 | 投稿作成画面を再表示 |
| キャプション編集 | 投稿一覧 | 投稿一覧でエラーを表示 |
| 投稿削除 | 投稿一覧 | 投稿一覧でエラーを表示 |

## 6. 実装時の確認項目

- `docs/screens.md`とURL、HTTPメソッド、テンプレート名が一致している。
- 未ログインでも投稿一覧を表示できる。
- 未ログインでは投稿作成、編集、削除、ログアウトを実行できない。
- 投稿者本人だけが編集と削除を実行できる。
- 外部URLを`next`に指定しても外部サイトへ転送されない。
- 存在しない投稿への編集・削除は404となる。
- 他人の投稿への編集・削除は403となる。
- CSRFトークンがない、または不正なPOSTは拒否される。
- データ変更処理はGETで実行できない。
- 投稿詳細といいねのルートが存在しない。
