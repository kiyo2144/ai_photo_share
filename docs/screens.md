# 写真共有アプリ 画面設計書

## 1. 画面設計の方針

- 投稿一覧を中心とした、初学者にも流れを追いやすい画面構成にする。
- 投稿一覧はログインしていない利用者も閲覧できる。
- 投稿の作成、編集、削除にはログインが必要となる。
- 投稿詳細画面は設けず、キャプションの編集と投稿の削除は投稿一覧内で行う。
- いいね機能は初版に含めない。

## 2. 共通レイアウト

### 2.1 共通テンプレート

- **テンプレート名**: `base.html`
- 各画面のテンプレートは`base.html`を継承する。
- ページタイトル、ヘッダー、ナビゲーション、フラッシュメッセージ、本文表示領域を共通化する。

### 2.2 ヘッダーとナビゲーション

すべての利用者に「投稿一覧」へのリンクを表示する。ログイン状態に応じて、次の項目を切り替える。

- 未ログイン時: 「ログイン」「ユーザー登録」へのリンク
- ログイン時: 「投稿する」へのリンクと「ログアウト」ボタン

ログアウトは状態を変更するため、リンクではなくPOST送信用のフォームとボタンにする。

### 2.3 メッセージ表示

- 登録、ログイン、ログアウト、投稿、編集、削除の結果をフラッシュメッセージで表示する。
- 入力項目に固有のエラーは、可能な限り対象項目の近くに表示する。
- 入力エラー後はメールアドレスやキャプションを保持してよいが、パスワードと画像ファイルの選択状態は保持しない。
- 予期しないエラーでは、内部の例外情報を画面に表示しない。

## 3. 投稿一覧（トップ）

- **目的**: 投稿を新しい順に閲覧し、投稿者本人がキャプションの編集や投稿の削除を行う。
- **ログイン**: 不要
- **URL**: `/`
- **HTTPメソッド**: `GET`
- **テンプレート名**: `posts/index.html`

### 3.1 表示内容

- 写真
- キャプション
- 投稿日時
- 投稿がない場合の案内メッセージ

投稿者のメールアドレスは表示しない。キャプションがない投稿も表示し、画像を読み込めない場合は代替テキストを表示して一覧全体の表示を継続する。

### 3.2 投稿者本人にだけ表示する操作

- 200文字以内のキャプション編集欄
- キャプションの「更新」ボタン
- 投稿の「削除」ボタン

削除ボタンを押したときはJavaScriptの確認ダイアログを表示する。キャンセル時は送信せず、了承した場合だけ削除フォームを送信する。

画面上で操作を隠すだけでなく、サーバー側でも投稿者本人か確認する。

### 3.3 画面遷移

- 「ログイン」→ ログイン画面
- 「ユーザー登録」→ ユーザー登録画面
- 「投稿する」→ 投稿作成画面
- キャプション更新成功・失敗 → 投稿一覧
- 投稿削除成功・失敗 → 投稿一覧
- ログアウト → 投稿一覧

## 4. ユーザー登録

- **目的**: メールアドレスとパスワードでアカウントを作成する。
- **ログイン**: 不要
- **URL**: `/register`
- **HTTPメソッド**: `GET`, `POST`
- **テンプレート名**: `auth/register.html`

### 4.1 入力項目

- メールアドレス
- パスワード
- 確認用パスワード

### 4.2 動作と画面遷移

- 登録成功 → 成功メッセージを設定し、ログイン画面へ移動
- 入力エラー → 同じ画面にエラーを表示
- 「ログインはこちら」→ ログイン画面
- 「キャンセル」→ 投稿一覧
- ログイン中のアクセス → 投稿一覧へ移動

パスワードと確認用パスワードが一致することを確認する。登録済みのメールアドレスは重複登録できない。

## 5. ログイン

- **目的**: 登録済みユーザーを認証し、会員向け機能を利用できる状態にする。
- **ログイン**: 不要
- **URL**: `/login`
- **HTTPメソッド**: `GET`, `POST`
- **テンプレート名**: `auth/login.html`

### 5.1 入力項目

- メールアドレス
- パスワード
- 元の目的画面を表す任意の`next`値

### 5.2 動作と画面遷移

- 通常のログイン成功 → 投稿一覧
- 投稿作成を試みた後のログイン成功 → 投稿作成画面
- 認証失敗 → 同じ画面にエラーを表示
- 「ユーザー登録はこちら」→ ユーザー登録画面
- 「キャンセル」→ 投稿一覧
- ログイン中のアクセス → 投稿一覧へ移動

`next`にはアプリ内の相対パスだけを許可する。外部URLや不正な値の場合は`next`を無視し、投稿一覧へ移動する。

## 6. 投稿作成

- **目的**: 写真1枚と任意のキャプションを投稿する。
- **ログイン**: 必須
- **URL**: `/posts/new`
- **HTTPメソッド**: `GET`, `POST`
- **テンプレート名**: `posts/new.html`

### 6.1 入力項目

- 写真ファイル（必須、JPEG・PNG・WebP、最大10MB）
- キャプション（任意、200文字以内）

フォームはファイルを送信できる形式にする。ブラウザ側の入力チェックだけに頼らず、サーバー側でも画像形式、容量、キャプションの長さを検証する。

### 6.2 動作と画面遷移

- 投稿成功 → 成功メッセージを設定し、投稿一覧へ移動
- 入力エラー → 同じ画面にエラーを表示
- 「キャンセル」→ 投稿一覧
- 未ログインでアクセス → `next=/posts/new`を付けてログイン画面へ移動
- ログイン成功後 → 投稿作成画面へ戻る

## 7. 画面遷移の全体像

```text
投稿一覧
├─ ユーザー登録 ─ 登録成功 ─ ログイン ─ 投稿一覧
├─ ログイン ─ 認証成功 ─ 投稿一覧
├─ 投稿作成 ─ 投稿成功 ─ 投稿一覧
├─ キャプション編集 ─ 更新成功・失敗 ─ 投稿一覧
├─ 削除確認ダイアログ
│  ├─ キャンセル ─ 投稿一覧に留まる
│  └─ 了承 ─ 投稿削除 ─ 投稿一覧
└─ ログアウト ─ 投稿一覧

未ログインで投稿作成へアクセス
└─ ログイン ─ 認証成功 ─ 投稿作成
```

## 8. 初版に含めない画面

- 投稿詳細画面
- いいねに関する画面や表示
- コメント、検索、フォロー、通知に関する画面
